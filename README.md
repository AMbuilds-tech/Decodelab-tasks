this decodelabs internship contain 3 projects
Project 1:
A rule-based chatbot that uses control flow and a dictionary-based knowledge base to match predefined user inputs with fixed responses. It runs in a continuous loop, sanitizes input, and falls back to a default reply for unrecognized commands until an exit command ends the session.

Project 2 — Data Classification Using AI
A supervised-learning pipeline that classifies Iris flowers into 3 species using K-Nearest Neighbors, covering the full data science workflow from loading and scaling data through training, tuning K via cross-validation, and evaluating with a confusion matrix and F1 score (93.3% test accuracy).

Project 3:
Tech Stack Recommender — a content-based recommendation engine that maps a user's input skills to relevant job roles using TF-IDF weighted vectors and Cosine Similarity, without relying on any historical user data.
It follows a full Input-Process-Output pipeline (ingest skills → vectorize & score → sort → filter) and returns the Top 3 best-matching career paths, with a fallback for cold-start cases where no skills overlap the dataset.
